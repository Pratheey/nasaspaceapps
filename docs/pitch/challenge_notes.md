# Challenge notes

**Challenge:** Dancing with the SARs (NASA Space Apps 2026). Build an interactive app that
uses NISAR radar data to track and visualize one or more types of surface change around the
world. Brief also asks for physical drivers, human drivers, polarization, and future NISAR use.

**Judging (global):** awards are given across all challenges, not per challenge. Local
event nominates first. Our best fits: **Best Use of Data**, **Best Use of Science**.

**Must-haves for submission:** project page text, 30-second video, public demo link, list of
NASA data used (with product names and maturity), team members.

**What other teams are doing (public repos, 14 Nov):** floods in Bangladesh, generic change
dashboards (floods, landslides, glaciers, vegetation), flood mapping in Valencia. Nobody we
found is doing seasonal rebound vs subsidence with held-out GPS.
